# INSIGHT 기사 이미지

관리화면(`/admin`)에서 본문에 이미지를 넣으면 **여기에 자동으로 올라간다.**
직접 넣을 일은 거의 없다.

## 올리기 전에 — 압축은 필수

원본 그대로 올리면 안 된다. 아이폰 사진 한 장이 5MB 인데,
그대로 쌓이면 사이트가 무거워지고 Cloudflare 빌드도 느려진다.

| 항목 | 기준 |
|---|---|
| 형식 | **WebP** (JPEG·PNG 도 되지만 무겁다) |
| 긴 변 | **1600px** 이하 |
| 용량 | **300KB** 이하 |

압축 도구: https://squoosh.app (브라우저에서 바로. 설치 불필요)

## 파일 이름

`YYYY-MM-DD-내용.webp` — 예) `2026-08-26-naver-search-result.webp`
어느 글의 이미지인지 나중에 알아볼 수 있어야 한다.

## ⚠️ 이미지 안의 글자는 검색·AI 가 읽지 못한다

「NAVER 점유율 62.57%」 같은 숫자를 이미지로만 두면
생성형 엔진의 인용 대상에서 빠진다.
**숫자와 결론은 반드시 본문 텍스트나 표에 둘 것.**
이미지는 어디까지나 증거·분위기 담당이다.
